# Engineering

How BachelorHouse is built. The **backend** (`bachelor-house-backend`, branch `chore/scaffold-from-reference`) is a TypeScript modular monolith on Express 5, PostgreSQL and Redis. The **website** (`bachelor-house-client`, `main`) is a Next.js 16 app. For what the product does and how much of it is built, see the [Product guide](/product).
