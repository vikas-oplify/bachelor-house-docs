# Error codes

:::info[Generated page]

Generated by `npm run sync` from **bachelor-house-backend** `chore/scaffold-from-reference`. Don't edit it by hand: the next sync overwrites it.

Every API error has the same shape, and `code` is one of the 71 below. The message is the safe default shown to users; a route may replace it with a more specific one.

```json
{ "error": { "code": "PLAN_REQUIRED", "message": "…", "requestId": "…", "details": {} } }
```
