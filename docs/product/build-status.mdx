# What's built today

BachelorHouse is mid-build. The backend has most of the listing, review, KYC, checkout and account rules in place. The tenant side of the marketplace (search, enquiries, chat) is not built. The website has the main screens, but **none of them call the backend yet**: every form is UI only.

## Legend

| Pill | Meaning |
| --- | --- |
| <Status s="built" /> | Works end to end in the backend. You can call it and the rule holds. |
| <Status s="partial" /> | Some of it works. The linked page says which part. |
| <Status s="screen" /> | A website screen exists but is not connected to the backend. |
| <Status s="none" /> | Not built. Rules may be decided, but there is no code. |

There is **no admin website**. Everything staff do today is through the admin API.
